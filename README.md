# snowfallen 
Made with Godot Engine

## Gameplay

- 3D third-person shooter game!
- Slide down a slope and shoot enemies
- Traverse around obstacles by jumping and sliding
- Features artworks drawn by me!

[YouTube - Brief Showcase of Game in Hack Club Video](https://www.youtube.com/watch?v=kkbf092Los0&t=2m52s)

## Controls
- WASD or Arrow Keys to move
- Mouse to look around
- Left Shift to slide
- Left Click to shoot
- Right Click to aim
